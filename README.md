### 👨‍💻 About Me

I learn by rebuilding things from first principles. The best way I know to understand a system is to write it myself — so I build **CPU emulators, interpreters, and games**, mostly in **Rust**: a [Game Boy](https://github.com/emadb/gameboy), an [Intel 8080 / Space Invaders](https://github.com/emadb/space_invade.rs) machine, a [Chip-8](https://github.com/emadb/chip-8), and more. Opcodes, timing, bit-twiddling and memory maps are where I have the most fun.

By day, I'm a **Software Engineer** and **Co-founder** at [**CodicePlastico**](https://codiceplastico.com), based in **Brescia, Italy 🇮🇹**, where I work on **Domain-Driven Design**, **event sourcing**, and the **actor model** — building robust, maintainable software.

- 🔭 Currently deep-diving into **Rust** & **Elixir**, and poking at **embedded** hardware (ESP32).
- 💬 Ask me about **emulation, DDD, Event Sourcing, TDD & Functional Programming**.
- 🎤 I love sharing knowledge at conferences like **WebDay**, **Codemotion**, and **RubyDay**.
